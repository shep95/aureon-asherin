# aureon landing page

Static HTML, CSS, JavaScript and local video assets from the current published landing page.

## run locally

From this directory run `python3 -m http.server 8000`, then open http://localhost:8000.
No package installation or build step is required.

## authentication status

Email/password forms are present, but no authentication backend is connected. Submitting does not create accounts or send credentials. Connect a production authentication provider before enabling registration, login, or password recovery.

## verification

JavaScript syntax and static checks passed. Live browser visual verification was blocked in the authoring environment.
